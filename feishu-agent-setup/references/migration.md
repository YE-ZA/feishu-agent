# 公共迁移检查

## 同账号、同 App 换电脑

记录非秘密绑定：profile、App ID、owner open_id，以及目标功能的文档和服务信息。新机按[公共搭建](setup.md)定位程序、依赖 Skills，安全绑定同应用并重新授权同用户；缺 App 凭据时走官方取得或重置流程；不整目录复制 CLI 凭据库，不从旧库提取令牌。config 不是登录态。

同 App 换电脑先核对已有机器人、权限、事件和命令，不重新创建。profile 名和路径变化不代表换账号，仍须核实 App 与 owner。业务文档、运行配置、SQLite、绘图素材及 Codex 登录/自动化由对应功能的迁移说明处理。

切换监听与调度前停止旧机对应功能，保留无关服务。两台独立状态库不能全局去重；只切换 todo 时不停止 draw，反之亦然。目标系统的凭据刷新、后台运行和消息收发需实际验收。

## 换账号、租户或 App

按[公共搭建](setup.md)核实新的 profile、user/bot 和发布状态。新 App 配置机器人、事件和当前功能所需权限；本人 open_id 按新 App 重新解析。

各功能使用新运行实例与空状态，不导入旧绑定的队列或发送回执，不删绑定校验绕过不匹配。旧文档的访问或复制按功能说明及 lark-drive/lark-wiki 处理，不能凭旧 token 绕过访问。完成目标功能验收后再切换其服务和调度。

## 分发

安装 draw 或 todo 时同时安装 feishu-agent-setup，保持公共与功能 Skill 平级；只安装需要的功能及其依赖。公共 Skill 仅包含通用操作说明，不打包个人配置、Secret、令牌、状态或业务数据。
